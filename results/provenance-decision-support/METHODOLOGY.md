# Methodology

This is a provenance decision-support benchmark, not a general coding-agent efficiency benchmark. Ten new paired fixtures are deliberately executed. The hidden oracle records the harness-planned commands, inputs, outputs, renames, order, session metadata, and intentional observation boundary independently of WhyFS. BASELINE and WHYFS receive identical provenance-explicit prompts; only WHYFS receives the frozen native MCP tool inventory. Each run is a fresh Codex 0.147.0 session using gpt-5.6-sol with medium reasoning. No agent may modify files, read another fixture, access the oracle, or access prior evidence. Correct uncertainty is epistemically correct even when runtime facts cannot be recovered from baseline evidence; recovery and precision are scored separately.

Each required oracle fact is classified as recovered from established evidence, correctly stated but explicitly labeled inference, calibrated unknown, incorrect/unsupported assertion, or omitted. Established facts and correct labeled inferences count toward value recovery; calibrated unknowns do not count as recovered but are not factual errors. Factual precision includes only asserted required-fact values. Decision quality is scored independently as PASS, PARTIAL, or FAIL.

Manual provenance reconstruction counts a command batch used to search, read, inspect metadata, or inspect Git in order to reconstruct provenance. General command batches are counted once even if they contain several subcommands. Typed WhyFS calls, their output bytes, ordinary reconstruction before/after tool use, raw Codex JSONL usage, context bytes, and wall time are recorded separately.

The first treatment collection was invalidated because the legacy WhyFS CLI was shell-accessible. Two replacement runs were later invalidated because the globally importable Python API remained accessible. All invalid runs are preserved; the final primary set retains the ten valid original baselines and uses fresh typed-only treatment fixtures. Pre-agent collector-readiness failures did not produce primary runs. The product, prompts, oracle, facts, decisions, and scoring rubric did not change during collection.
